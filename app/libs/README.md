# OpenCV AAR (optional)

Place a renamed OpenCV Android AAR here as `opencv.aar` to override the Maven dependency.

If this file is absent, Gradle uses `com.quickbirdstudios:opencv:4.5.3.0` from Maven Central.

To use the official SDK AAR: download [OpenCV Android SDK](https://github.com/opencv/opencv/releases), extract, and copy the release AAR from the SDK module into this folder as `opencv.aar`.
